# Tech Stack - Git Context

## Core Technologies
- **Language:** TypeScript
- **Runtime:** Node.js / VS Code Extension Host
- **Frontend:** React (Webview)
- **Database:** SQLite (via `sql.js`)
- **Analysis:** Tree-sitter (WASM) & Difftastic

## Intelligence & Search
- **LLM Integration:** OpenRouter (Cloud) & Ollama (Local)
- **Vector Search:** Qdrant (Semantic search & embeddings)
- **Context Management:** MCP (Model Context Protocol) Server

## Development & Infrastructure
- **Build System:** npm / esbuild / tsc
- **Testing:** Vitest (Unit/Integration)
- **CI/CD:** GitHub Actions (implied by repository structure)
